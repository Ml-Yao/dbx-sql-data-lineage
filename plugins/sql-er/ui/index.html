数据字典

管理字典来源、生成字典、导出文件；勾选即激活，多份字典自动合并

1

已绑定字典

勾选 = 激活并参与解析；移除只解除绑定，不删除已落盘的字典文件

2

导入字典文件

本地 JSON / CSV / XLSX，可多选；带「表注释 / 字段注释」列会直接作为中文说明

导入后自动注册并激活；本地工作台会同步到你设定的数据文件夹，换浏览器也不丢。
3

从 DBX 数据连接生成

只读系统视图；表/字段说明会在多个元数据视图之间自动回退查找

该能力在 DBX 插件版可用。本地工作台请直接用第 2 区「绑定文件」导入字典。
4

保存到目录

把字典写成标准 JSON，跨浏览器 / 工作台共用

该能力在 DBX 插件版可用。本地工作台的字典会自动保存到设定目录，无需手动导出。
字典提供表与字段的中文说明，并展示已保存的关联关系；说明缺失时显示原名。
